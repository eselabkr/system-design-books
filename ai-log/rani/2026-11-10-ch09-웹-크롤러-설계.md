# 웹 크롤러
🔵 웹 크롤러 개념은 이해했으나 로봇, 스파이더 개념이 모호함  
- 로봇(Robot) : 웹페이지를 자동으로 방문하고 정보를 수집하는 프로그램
- 스파이더(Spider) : 웹페이지의 링크를 따라 이동하며 정보를 수집하는 프로그램
- 웹 크롤러(Crawler) : 로봇, 스파이더와 같은 의미로 사용되는 용어

Q) 웹 크롤러에 대해서 추가 설명이 필요해 (책에 있는 내용 적음)  
A) 인터넷을 돌아다니면서 웹페이지의 정보를 자동으로 수집하는 프로그램
- 검색 엔진(구글, 네이버 등)에서 주로 사용
- 특정 웹페이지에서 시작하여 링크를 따라 다른 페이지로 이동
- 새로운 페이지나 갱신된 정보를 발견하고 수집
- 수집된 정보는 검색 엔진의 색인 등에 활용됨

# HTML 다운로더
🔵 HTML 다운로더와 미수집 URL 저장소 개념 이해 X  
- 미수집 URL 저장소에서 다운로드할 URL을 전달받음  
- 전달받은 URL에 HTTP 요청을 보냄  
- 서버가 응답한 HTML 데이터를 다운로드함  
- 동작 흐름  
1. 미수집 URL 저장소에서 URL 제공  
2. HTML 다운로더가 해당 URL에 접속  
3. 웹 페이지의 HTML 다운로드  

Q) HTML 다운로더에 대해서 설명해줘  
A) HTML 다운로더 : 전달받은 URL에 실제로 접속해서 HTML을 가져오는 곳  
미수집 URL 저장소 : 어디에 접속해야 하는지 URL을 관리하는 곳  

# 컨텐츠 파서
🔵 콘텐츠 파서 단순 개념 외 이해 X 

Q) 컨텐츠 파서에 대해서 알려줘 + 크롤링 서버 안에 콘텐츠 파서를 구현하면 느려질 수 있는 이유와 독립된 컴포넌트로 하는 이유
A) HTML 다운로더가 웹 페이지를 가져오는 역할이라면, 콘텐츠 파서는 가져온 웹 페이지가 정상적인지 확인하고 내용을 분석하는 역할  
크롤링 서버가 웹 페이지 다운로드아 HTML 분석과 검증까지 모두 담당할 경우 순차적으로 처리하는데 오래 걸릴수 있는데  
콘텐츠 파서를 별도 컴포넌트로 분리하면 다운로드와 파싱을 각각 독립적으로 처리할수 있다.
* 분리한다고 개별 페이지의 처리 시간이 반드시 줄어드는 것은 아니지만 다운로드와 파싱을 병렬로 처리하거나 각 컴포넌트를 독립적으로 확장 가능함.

# 상대경로와 절대경로
Q) 상대경로와 절대경로에 대해서 정리해줘
A) 
- 절대경로(Absolute Path)
: 전체 위치를 나타내는 경로
- 예시: https://example.com/shop/a.html
- 현재 페이지 위치와 관계없이 동일한 URL을 가리킴

- 상대경로(Relative Path)
: 현재 페이지 위치를 기준으로 나타내는 경로
- 예시: shop/a.html
- ./ : 현재 디렉터리
- ../ : 상위 디렉터리
- / : 사이트 루트 경로

* 웹 크롤러에서의 활용
- 웹 페이지의 상대경로를 절대 URL로 변환
- 변환된 URL을 통해 새로운 웹 페이지 다운로드
