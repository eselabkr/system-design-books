## 준비 체크리스트

### 지식

- [ ] 각 영역 README의 체크리스트를 절반 이상 채웠다
- [ ] 정리한 주제를 문서 안 보고 설명할 수 있다
- [ ] 각 주제마다 "왜 그렇게 설계됐나"를 한 문장으로 말할 수 있다

### 경험

- [ ] 주요 프로젝트 3개를 STAR로 정리했다
- [ ] 각 프로젝트에서 내린 기술적 결정과 그 이유를 말할 수 있다
- [ ] 실패했거나 아쉬웠던 경험을 하나 준비했다

### 마무리

- [ ] 자기소개 1분 버전을 준비했다
- [ ] 역질문 3개를 준비했다
